# tools/split

Re-runnable god-file split for issue #29 (structural refactor).

- `split-map.json`: for each god file, the new files and the top-level definitions each receives
  (exact names, then patterns), and the names that stay in the god file on purpose.
- `apply_split.py`: applies the map. It moves whole top-level blocks verbatim (with the comment
  written directly above them, in their original order), keeps every file-local symbol with all of
  its users, puts macros and types shared by several files of a module into `<Module>Internal.h`,
  moves the prototypes that only the module uses from `<Module>.h` to `<Module>Internal.h`, and
  reports what the map does not place or what a file-local symbol keeps back.
- `check_moves.py`: proves that a commit only moves blocks (byte for byte, order kept) and adds
  nothing but includes, copied include blocks, include guards and CMake source names.
- `splitlib.py`: the top-level C parser both scripts share.

Re-run on a new tree (for example after #24 and #28 land):

```
git checkout -b structure-rerun origin/master
python tools/split/apply_split.py            # --dry-run --explain to preview
python tools/split/check_moves.py --worktree
git add -A src && git commit -m "structure: split god files by responsibility (generated by tools/split, Refs #29)"
```

Run it on the unsplit tree: a second run on its own output changes nothing, but it does not move
blocks between files it already created.

When the tree has drifted from the map, the tool warns and goes on; it never stops on the map:

- a map name or pattern that matches no definition (deleted or renamed) places nothing, and the
  warning names the closest unmapped definitions;
- a god file that is missing or does not parse skips its module, and the other modules still split;
- `--reference REV` (for example the last split commit) lists the definitions that land in another
  file than in REV. A function that an `#if` region used to carry along, and that is now at the top
  level, shows up here when the map does not name it.

Commit the map fix on its own, before the generated commit, so that `check_moves.py` sees only moves.
