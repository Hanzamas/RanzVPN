Ranz controller

Sign in with an API token. The web UI calls the controller's API with it, so it can do what the token's role allows: a viewer reads, an operator also applies Intent, an admin also manages the API tokens.

The first start of the controller writes the secret of the admin token to admin.token in its data directory. ranz token create makes a token for each person or tool. The token stays in this tab until you sign out or close it.

Not an administrator? Sign in to the portal with your user name and your password to see and manage your own devices.
