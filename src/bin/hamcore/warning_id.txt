PENGUMUMAN PENTING TENTANG RANZ VPN

RANZ VPN ADALAH SERVER VPN UNTUK WINDOWS YANG DITURUNKAN DARI SOFTETHER VPN. FUNGSI KOMUNIKASI VPN-NYA SANGAT KUAT DAN AKAN MEMBERIKAN ANDA MANFAAT BESAR. NAMUN, JIKA ANDA MENYALAHGUNAKAN PERANGKAT LUNAK INI, HAL INI DAPAT MERUGIKAN ANDA SENDIRI ATAU ORANG LAIN. UNTUK MENGHINDARI RISIKO TERSEBUT, DOKUMEN INI BERISI PENGUMUMAN PENTING UNTUK SIAPA PUN YANG INGIN MENGGUNAKAN PERANGKAT LUNAK INI. PETUNJUK BERIKUT SANGAT PENTING. BACA DAN PAHAMI DENGAN SEKSAMA. RANZ VPN TIDAK BERISI LAYANAN INTERNET DARI SOFTETHER VPN (DYNAMIC DNS, NAT TRAVERSAL, VPN AZURE, VPN GATE, DAN LAYANAN CLOUD LAINNYA), DAN TIDAK MENGIRIM INFORMASI APA PUN KE SOFTETHER CORPORATION, KE HANZCODES, ATAU KE OPERATOR LAYANAN LAIN MANA PUN. LIHAT BAB 3.


1. Protokol Komunikasi VPN
1.1. Protokol SE-VPN
Ranz VPN mengimplementasikan "Protokol SoftEther VPN (SE-VPN Protocol)" dari SoftEther VPN. Protokol SE-VPN mengenkapsulasi paket Ethernet apa pun ke dalam koneksi HTTPS (HTTP over TLS). Oleh karena itu, protokol SE-VPN dapat berkomunikasi melewati firewall bahkan jika administrator jaringan mengonfigurasi firewall untuk memblokir paket VPN tradisional. Protokol SE-VPN dirancang dan diimplementasikan untuk mematuhi TLS (RFC 5246 dan RFC 8446) dan HTTPS (RFC 2818). Namun, terkadang perilakunya berbeda dari RFC. Jika Anda adalah seorang administrator jaringan dan ingin memblokir protokol SE-VPN pada firewall, Anda dapat menerapkan kebijakan "daftar putih" pada firewall untuk memfilter semua paket TCP atau UDP di perbatasan kecuali paket yang secara eksplisit diizinkan menuju situs web dan server tertentu. Ranz VPN Server yang baru (yang belum memiliki file konfigurasi) mendengarkan pada port TCP 443 dan 5555. Kedua port membawa sesi VPN dan koneksi administrasi.

1.2. Percepatan UDP
Ranz VPN memiliki fungsi Percepatan UDP (UDP Acceleration). Jika kedua ujung sesi VPN mendeteksi bahwa saluran UDP dapat dibuat di antara keduanya, UDP akan digunakan secara otomatis. Dengan fungsi ini, throughput meningkat. Ranz VPN hanya menggunakan paket UDP langsung: Ranz VPN tidak memiliki "UDP Hole Punching" dan tidak menggunakan server cloud apa pun untuk membuat saluran UDP. Jika administrator mengisi server STUN pada item "StunServer" di folder "ServerConfiguration" pada file konfigurasi, server mengirim permintaan STUN ke server tersebut untuk mengetahui alamat UDP publiknya. "StunServer" kosong secara default, dan dalam keadaan itu tidak ada permintaan STUN yang dikirim. Percepatan UDP dapat dinonaktifkan kapan saja di sisi klien.

1.3. Fungsi yang Tidak Disertakan
Ranz VPN hanya berisi protokol SE-VPN dari SoftEther VPN. Ranz VPN tidak berisi VPN melalui ICMP, VPN melalui DNS, R-UDP, OpenVPN, L2TP/IPsec, IPsec/IKE, EtherIP, SSTP, WireGuard, maupun PPP. Ranz VPN juga tidak berisi SoftEther VPN Client, SoftEther VPN Bridge, program GUI, program instalasi, fungsi Virtual NAT dan Virtual DHCP (SecureNAT), autentikasi RADIUS, autentikasi kartu pintar (PKCS#11), clustering, JSON-RPC, maupun konsol web HTML5. Pengumuman SoftEther VPN tentang fungsi-fungsi ini tidak berlaku untuk Ranz VPN.


2. Perangkat Lunak Ranz VPN
2.1. Ranz VPN Server
Ranz VPN terdiri atas program tanpa antarmuka grafis untuk Windows 10, Windows Server 2016, dan versi yang lebih baru, pada x64 dan arm64: vpnserver.exe (server VPN), vpncmd.exe (alat administrasi baris perintah), dan vpntest.exe (diagnostik). Tidak ada GUI dan tidak ada program instalasi. vpnserver.exe berjalan sebagai layanan Windows "Ranz VPN Server", yang didaftarkan oleh "vpnserver /install", atau sebagai proses biasa (bagian 2.3). Program ini menyimpan file konfigurasinya "ranz_server.config", cadangan file tersebut, dan log-lognya di folder vpnserver.exe, serta sebagian data di kunci registry "Software\Hanzcodes\Ranz VPN".

2.2. Local Bridge
Jika Anda menggunakan fungsi "Local Bridge" (misalnya perintah vpncmd BridgeCreate atau BridgeDeviceList), Ranz VPN Server menginstal driver SeLow pada komputer. SeLow adalah driver protokol NDIS mode kernel yang mengirim dan menerima paket Ethernet pada adaptor jaringan fisik. Driver ini ditandatangani secara digital oleh Microsoft (Windows Hardware Compatibility Publisher). Driver ini hanya tersedia untuk x64, sehingga Local Bridge tidak tersedia pada arm64. Setelah terinstal, driver ini dimulai bersama Windows. Driver ini tetap terinstal setelah Anda menghapus Ranz VPN; Anda dapat menghapusnya secara manual.

2.3. Menjalankan Tanpa Layanan Windows
"vpnserver /usermode" menjalankan Ranz VPN Server sebagai proses biasa dari pengguna yang memulainya, tanpa layanan Windows dan tanpa hak administrator sistem. Dalam mode ini, program tidak menampilkan jendela maupun ikon di task-tray. Oleh karena itu, misalnya, seorang karyawan dapat menjalankan Ranz VPN Server di komputer dalam jaringan kantor dan terhubung ke server tersebut dari rumahnya. Dari sudut pandang teknis, tidak diperlukan hak administratif sistem untuk hal ini. Namun, melanggar peraturan perusahaan dengan menjalankan perangkat lunak pada komputer tanpa izin dapat dianggap sebagai tindakan yang tidak diinginkan. Jika Anda seorang karyawan dan kebijakan perusahaan melarang pemasangan perangkat lunak atau komunikasi ke Internet tanpa izin, Anda harus mendapatkan izin dari administrator jaringan atau pejabat eksekutif perusahaan Anda terlebih dahulu. Anda tidak boleh menjalankan Ranz VPN Server di komputer orang lain tanpa persetujuan pemiliknya. Tindakan seperti itu dapat dianggap sebagai pelanggaran hukum pidana.

2.4. Penghapusan
Ranz VPN tidak memiliki program penghapus instalasi. Untuk menghapusnya, jalankan "vpnserver /uninstall" untuk menghentikan dan menghapus layanan Windows, lalu hapus file program. File konfigurasi, cadangannya, dan log tetap berada di folder vpnserver.exe sampai Anda menghapusnya. "vpnserver /uninstall" juga menghapus aturan Windows Firewall milik server (bagian 2.6). Kunci registry "Software\Hanzcodes\Ranz VPN" dan driver SeLow (bagian 2.2) tidak dihapus secara otomatis. Hapus secara manual jika Anda tidak lagi membutuhkannya.

2.5. Keamanan
Atur kata sandi administrator Ranz VPN Server (perintah vpncmd ServerPasswordSet) segera setelah server pertama kali dijalankan. Sebelum Anda mengaturnya, orang lain yang dapat terhubung ke server dapat mengaksesnya sebagai administrator dan dapat mengatur kata sandi tanpa izin Anda.

2.6. Windows Firewall
"vpnserver /install" menambahkan satu aturan masuk bernama "Ranz VPN Server" ke Windows Firewall. Aturan ini mengizinkan vpnserver.exe pada semua protokol dan port, di semua profil jaringan. "vpnserver /uninstall" menghapus aturan tersebut. Ranz VPN Server tidak menambahkan aturan firewall apa pun saat dijalankan, dan tidak ada aturan yang ditambahkan untuk vpncmd.exe atau vpntest.exe.

2.7. Log
Ranz VPN Server menulis log server, dan setiap Virtual Hub dapat menulis log keamanan dan log paket (perintah vpncmd LogEnable dan LogPacketSaveType), ke folder vpnserver.exe. Log paket merekam header dari paket yang melewati Virtual Hub. Bersama log keamanan, log ini dapat membantu menemukan pengguna yang memulai suatu komunikasi. Rekam dan gunakan log ini hanya untuk tujuan yang sah. Jangan mengintip atau membocorkan log ini kecuali untuk tujuan yang benar, dan lindungi privasi komunikasi pengguna Anda.


3. Koneksi Jaringan dan Privasi
3.1. Tanpa Layanan Internet
Ranz VPN tidak berisi layanan Internet dari SoftEther VPN: Dynamic DNS, NAT Traversal, UDP Hole Punching, VPN Azure, VPN Gate, server cloud proxy DNS, fungsi Keep Alive, dan pemberitahuan pembaruan otomatis. Ranz VPN tidak bergantung pada server apa pun yang dioperasikan oleh SoftEther Corporation, oleh Hanzcodes, atau oleh operator layanan lain, dan tidak mengirim informasi apa pun kepada mereka.

3.2. Koneksi yang Dibuat oleh Ranz VPN Server
Ranz VPN Server menerima koneksi VPN dan koneksi administrasi pada listener-nya. Server hanya membuat koneksi keluar ke host yang dikonfigurasi oleh administrator: server tujuan koneksi Cascade, server syslog, server STUN (bagian 1.2), dan, saat administrator mengatur sertifikat server (perintah vpncmd ServerCertSet), alamat yang disebutkan dalam sertifikat tersebut tempat sertifikat CA perantara yang belum ada diunduh. Nama host diterjemahkan melalui server DNS yang dikonfigurasi di Windows.


4. Peringatan Umum
4.1. Memerlukan Persetujuan dari Administrator Jaringan
Protokol SE-VPN terlihat seperti HTTPS, sehingga dapat melewati firewall dan server proxy yang mengizinkan HTTPS tanpa pengaturan khusus oleh administrator jaringan. Namun, setiap karyawan yang bekerja di perusahaan harus mendapatkan persetujuan dari administrator jaringan sebelum menggunakan Ranz VPN di jaringan perusahaan. Jika administrator jaringan Anda mengabaikan permintaan persetujuan tersebut, Anda dapat mempertimbangkan untuk meminta persetujuan dari otoritas yang lebih tinggi (misalnya, pejabat eksekutif perusahaan). Jika Anda menggunakan Ranz VPN tanpa persetujuan dari otoritas perusahaan, Anda mungkin mengalami kerugian. Pengembang Ranz VPN tidak akan pernah bertanggung jawab atas hasil atau kerugian yang ditimbulkan akibat penggunaan Ranz VPN.

4.2. Patuhi Hukum di Negara Anda
Jika hukum di negara Anda melarang penggunaan enkripsi, Anda harus menonaktifkan fungsi enkripsi Ranz VPN sendiri (misalnya dengan perintah vpncmd CascadeEncryptDisable). Demikian pula, di beberapa negara atau wilayah, beberapa fungsi Ranz VPN mungkin dilarang oleh undang-undang, dan sebagian dari Ranz VPN mungkin melanggar paten yang hanya berlaku di wilayah tertentu. Anda harus memverifikasi legalitas penggunaan Ranz VPN di wilayah Anda sebelum benar-benar menggunakannya di sana. Secara alami, ada hampir 200 negara di dunia, dan setiap negara memiliki hukum yang berbeda. Secara praktis, tidak mungkin untuk memverifikasi hukum dan regulasi setiap negara serta memastikan perangkat lunak mematuhi semuanya sebelum dirilis. Jika seorang pengguna menggunakan Ranz VPN di negara tertentu dan mengalami kerugian akibat tindakan pegawai pemerintah setempat, pengembang Ranz VPN tidak akan pernah bertanggung jawab untuk mengganti atau menanggung kerugian tersebut, termasuk tanggung jawab pidana.

4.3. Perangkat Lunak Pihak Ketiga
Ranz VPN berisi perangkat lunak dari pihak ketiga, antara lain SoftEther VPN, OpenSSL, zlib, liboqs, dan oqs-provider. Pemberitahuan hak cipta dan lisensinya terdapat di legal.txt, yang ditampilkan oleh perintah vpncmd About.
